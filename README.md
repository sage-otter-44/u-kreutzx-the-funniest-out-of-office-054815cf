One line of out-of-office auto-reply, 127 characters. A concrete office
handoff with the twist saved for the last clause: Dave is covering the
inbox — and Dave turns out to be the printer.

> Out until Monday. Dave is covering my inbox — he's eaten two invoices, jammed twice, and just so you know, Dave is the printer.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (exactly one line, no trailing
newline). `main.ts` checks the gate itself: 1–140 characters, non-blank,
single line.
